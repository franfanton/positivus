# 🌟 Next.js 15 project with Tailwind CSS

Welcome to this project developed with Next.js 15, React and Tailwind CSS! 🚀

## 📌 Features.

- ⚡️ Next.js 15 for efficient rendering.
- 🎨 Styling with Tailwind CSS
- ♻️ Reusable components in React

## 🚀 Installation and Use

### 1️⃣ Clone the repository

```bash
git clone https://github.com/franfanton/positivus.git
cd positivus
```

### 2️⃣ Install dependencies

```bash
npm install  # o pnpm install / yarn install
```

### 3️⃣ Running the server in development

```bash
npm run dev
```

The project will be available at `http://localhost:3000/`
